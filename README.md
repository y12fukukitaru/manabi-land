# まなびランド 🎈

5つの学習アプリを1つにまとめた、おうち用の学習ポータルです。
どのアプリで遊んでも、共通の「シールちょう」にシールが貯まります。

## 収録アプリ

| アプリ | 内容 | シールがもらえるタイミング |
|---|---|---|
| 🍓 いちごさんすう | たし算〜わり算(手書き入力) | ステージ/チャレンジクリア(アプリ内と同じシールが図鑑にも登録) |
| 🌳 かんじの もり | 漢字カード・なぞり書き・クイズ | クイズ合格で「漢字はんこ」/ なぞり書き3文字ごと / カテゴリのカード制覇 |
| 📚 ことばの ほんだな | 熟語カード・ミニ絵本 | クイズ全問クリア / 絵本1冊読了(初回はレア率UP) / カテゴリ制覇 |
| 🌏 えいご アドベンチャー | 英単語・ABC・リスニング | 各モードのクリア / カテゴリの単語ぜんぶ見る / ABC・なぞり制覇 |
| 🚀 うちゅうの かたち たんけん | 図形・回転・積み木クイズ | ラウンドで⭐3以上(パーフェクトはレア率UP) / ロケット発射 |

## シールちょう(中央システム)

- **シール257種類**: 6テーマ×220種(ふつう/レア/スーパーレア) + 漢字はんこ24種 + ひみつのシール13種
- **ペタペタボード**: 獲得したシールを好きな場所に貼って遊べる(長押しではがす)
- **ずかん**: テーマごとにコレクション率を表示。未獲得は「？」
- **ひみつのシール**: 「ロケット発射」「はんこ10個」「図鑑コンプ」など条件達成で自動獲得
- **きろく**: 全アプリの実績カウンター

未所持シールが優先で当たる仕組みなので、遊ぶほど図鑑が埋まります。

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリを作成(例: `manabi-land`)。自宅用なら **Private でも可**(Pages は Free プランでは Public リポジトリのみ。Private で公開したい場合は Pro プラン)
2. このフォルダの中身をそのままアップロード
   ```
   index.html
   bridge.js
   README.md
   apps/ (5ファイル)
   ```
3. リポジトリの **Settings → Pages** を開き、
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)` → **Save**
4. 数分後に `https://<ユーザー名>.github.io/manabi-land/` で開けます
5. スマホ/タブレットで開いて「ホーム画面に追加」するとアプリのように使えます

## 注意事項

- **データ保存**: シール・記録はブラウザの localStorage に保存されます。端末・ブラウザごとに別データです。閲覧履歴の削除で消えるのでご注意ください
- **手書き認識(いちごさんすう)**: GitHub Pages 上ではAI認識は動かないため、内蔵のローカル認識に自動で切り替わります(🔢テンキー入力も使えます)
- **音声**: 端末の読み上げ機能(SpeechSynthesis)を使用。初回はタップ後に有効になります
- **ローカルで試す場合**: `file://` で直接開くと保存が不安定な場合があります。フォルダ内で `python3 -m http.server` を実行し `http://localhost:8000` で開くのがおすすめです

## 構成

- `index.html` — ホーム画面 + シールちょう本体
- `bridge.js` — 全アプリ共通のシール付与・保存・演出システム
- `apps/*.html` — 各アプリ(末尾に連携用パッチを追加済み。元の機能はそのまま)
